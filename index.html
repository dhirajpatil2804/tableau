Lesson 01 · Foundation

What is Tableau?

Tableau is a visual analytics tool: instead of reading thousands of rows, you turn data into interactive views so patterns and questions become easier to see.

Start with a question

Good Tableau work begins with a question, not a chart.

Question: Which product category generates the most sales?

Mindset: every field you place into the view changes the question you are asking of the data.

Lesson 02 · Data

Understand your data before you visualize it

A Tableau workbook starts with a data source. Learn what a row, field, dimension, measure, date and geography mean before dragging everything everywhere.

Dimensions vs Measures

Dimensions

Describe or slice the data.

  • Category
  • Region
  • Customer Name
  • Order Date
Measures

Usually represent quantities you can aggregate.

  • Sales
  • Profit
  • Quantity
  • Discount

Simple rule: “What kind of thing?” → dimension. “How much/how many?” → measure.

See the data as rows

Tableau turns these fields into visual marks. A view can summarize many source rows into fewer marks.

Live connection or extract?

Tableau can work with live data connections or in-memory extracts. As a beginner, first understand the analysis workflow; performance and refresh choices come later.

Rows & Columns

These shelves structure the view. Put a dimension there to create headers; put a measure there to create an axis.

Try: Category → Columns, Sales → Rows. You just made a bar chart.

Marks card

The Marks card controls how marks look and what information they carry: color, size, shape, text/label, detail and tooltip.

Try: Region → Color. Now the bars are encoded by region.

Show Me is your beginner safety net

Select fields and use Show Me to see chart types that fit those fields. But don't blindly accept the chart—ask whether it answers your question.

Lesson 07 · Calculations

Teach Tableau new logic

Calculated fields let you create new information from existing data. Learn basic calculations first, then table calculations and LOD expressions.

Basic calculated field

Suppose your data has Sales and Profit, but you need Cost.

[Sales] - [Profit]

Or classify records:

IF SUM([Profit]) > 0 THEN "Profitable" ELSE "Nonprofitable" END

Three calculation families

Basic expressions
→
LOD expressions
→
Table calculations

Basic: transform or aggregate data.

LOD: control the granularity of a calculation.

Table calculation: transform values based on the current visualization.

LOD: FIXED in plain English

Imagine your view changes, but you want a calculation to stay at a particular level of detail.

{ FIXED [Customer Name] : SUM([Sales]) }
Read it as: “For each customer, calculate total sales at the customer level.”

Table calculation: think “after the view exists”

For example, a running total or moving average uses values already present in the visualization.

Beginner checklist

Before calling yourself “comfortable,” make sure you can:

  • Connect a dataset
  • Identify dimensions and measures
  • Build bar and line charts
  • Use Rows, Columns and Marks
  • Filter and sort
  • Create a calculated field
  • Build a dashboard
Quick reference

What to learn after the basics

Parameters

User-controlled values that can drive calculations, filters, reference lines and actions.

Sets

Custom subsets of data that can be used for comparison and analysis.

Groups

Combine related members into meaningful categories.

Bins

Create ranges of values for distributions such as histograms.

Maps

Use geographic fields to explore location-based patterns.

Storytelling

Sequence views to guide an audience through a data story.
